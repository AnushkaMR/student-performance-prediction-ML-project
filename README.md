# Student Performance Predictor

A full-stack machine learning web application that predicts a student's final academic grade using academic and personal information.

The project combines a Next.js frontend, FastAPI backend, and a Random Forest regression model built with Scikit-learn.

## Project Overview

Student Performance Predictor allows users to enter student information and receive a predicted final grade.

The application demonstrates how a machine learning model can be integrated into a real-world web application.

```text

  ↓
